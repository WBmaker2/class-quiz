# 🏛️ 초등학교 5학년 사회 퀴즈 | 조선 시대의 문화

초등학교 5학년 2학기 사회과 교육과정 성취기준에 맞춘 **조선 시대 문화 퀴즈 웹앱**입니다.  
교실 대형 TV(전자칠판) 및 학생들의 스마트폰/태블릿 어디에서든 크고 또렷하게 보이도록 설계되었습니다.

---

## 🌟 주요 기능 및 특징

1. **초등 5학년 사회과 핵심 10문항 수록**
   - 훈민정음(한글 창제), 앙부일구, 측우기, 조선 후기 서민 문화(판소리/탈춤/한글소설), 풍속화(김홍도), 조선 백자, 수원 화성(정약용과 거중기), 실학, 조선왕조실록, 민화 등 핵심 개념 반영
2. **한 문제씩 집중 풀이 & 즉각 피드백**
   - 4지선다 보기를 선택하는 즉시 정답/오답 판정 및 효과음 재생
   - 초등 5학년 눈높이에 맞춘 1~2문장의 친절한 핵심 해설 카드 제공
3. **교실 TV & 스마트폰 완벽 호환 디자인**
   - **글자 크기 3단계 조절:** 보통 / 크게 / **TV모드(아주 크게)**
   - 원거리 시청에 최적화된 높은 명도 대비(High-Contrast) 색상
   - 터치 및 마우스 클릭이 편리한 큼직한 버튼
4. **교실 수업용 편의 기능**
   - **전체화면(Full Screen) 버튼:** 전자칠판이나 TV에서 주소창 없이 꽉 찬 화면 지원
   - **키보드 단축키 지원:** 무선 프리젠터나 리모컨/키보드로 편리하게 조작
     - `1`, `2`, `3`, `4`: 보기 선택
     - `Space` 또는 `Enter`: 다음 문제로 넘어가기 / 다시 풀기
   - **사운드 온/오프:** Web Audio API 기반 경쾌한 효과음(딩동댕, 땡, 팡파르) 및 원클릭 음소거 지원
5. **결과 화면 & 다시 풀기**
   - 100점 만점 기준 총점 및 정답 개수 표시
   - 점수별 맞춤형 칭찬 칭호(예: *조선 최고의 학자! 집현전 대제학*)와 축하 꽃가루(Confetti)
   - **오답 노트 아코디언:** 틀린 문제만 모아서 해설과 함께 복습 가능
   - 언제든 처음부터 다시 도전할 수 있는 **[다시 풀기]** 버튼 제공

## 🚀 실행 방법

### 방법 1: 파일 직접 열기
- 폴더 내의 `index.html` 파일을 더블클릭하여 크롬, 엣지, 웨일 등 브라우저로 열면 즉시 실행됩니다. (별도 설치 불필요)

### 방법 2: 로컬 서버 실행 (선택 사항)
터미널에서 아래 명령어로 로컬 서버를 띄워 스마트폰과 같은 와이파이망에서 공유할 수 있습니다:
```bash
npx serve .
# 또는
python -m http.server 8080
```
